# 🔌 Smart Energy Monitoring System

## 🎯 Problem Statement
Electricity wastage in educational institutions due to lights/fans remaining ON in empty classrooms.

## 💡 Solution
Automated system using PIR sensors and Arduino to control appliances based on room occupancy.

## 🛠 Technology Stack
- *Hardware:* Arduino UNO, PIR Sensor, Relay Module, ESP8266
- *Software:* Arduino IDE, Google Firebase
- *Cloud:* Firebase Realtime Database

## 📊 Features
✅ Motion-based automatic control  
✅ Timer delay to prevent rapid switching  
✅ Real-time Firebase monitoring  
✅ Energy usage analytics  
✅ Scalable to multiple rooms
